# Icon catalogue licences

`icons.json` is generated by `npm run icons:build` from the packages below.
It contains their icon geometry, so their licences travel with this file and
with any deployment of this application.

Regenerating the catalogue after changing a source package means checking this
file still describes what is in it.

| Library | Prefix | Licence | Source |
|---|---|---|---|
| Lucide | `lucide:` | ISC | https://github.com/lucide-icons/lucide |
| Tabler Icons | `tabler:`, `tabler-filled:` | MIT | https://github.com/tabler/tabler-icons |
| Material Design Icons | `mdi:` | Apache-2.0 | https://github.com/Templarian/MaterialDesign |

Lucide is a runtime dependency of the application as well, for the fixed icons
in the interface. Tabler and Material Design Icons are development
dependencies only: nothing imports them at runtime, and they exist purely so
the generator can read their geometry.
